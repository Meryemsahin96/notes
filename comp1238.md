# COMP1238 - Midterm Notes

## Week 1 - Information Storage Before Computers
- History of writing: cuneiform ("wedge shaped" in Latin) on Sumerian clay tablets in Mesopotamia
- The Epic of Gilgamesh was epic
- Babylonian numbers used a base-60 system (that's why we have 60 minutes)
- One writing system can be used by many languages, e.g. Korean Hangul (15th century), Inuktitut syllabics in Canada (from 1870s)
- Printing press used movable metal type in a composing stick; typewriters used fixed-width fonts, later came proportional fonts

## Week 2 - Representing Text and Numbers in Computers
- "Bit" is short for "Binary Digit" - only two states (like Morse code: dot and dash)
- A byte is a group of 8 bits, it has 256 possible values
- Volatile memory (RAM) is erased when power is gone; non-volatile storage (hard drive, SD card, flash drive) keeps data
- RAM is much faster but more expensive than storage
- All data is stored as sequences of bytes; the ASCII table maps numbers to characters

## Week 3 - Text Structure & Markup Languages
- Alphanumeric = letters and digits; everything else (like ( ) [ ] { } < >) is non-alphanumeric
- Hex numbers are a short way to write bytes, e.g. "(" is 0x28 in ASCII
- Markup existed before computers: editors used proofreading marks on paper
- Markdown: `#` for headings, `-` for bullet lists, `[text](url)` for links

## Week 4 - Keyboards & Editors
- QWERTY layout came from typewriters - keys were placed so common letter pairs wouldn't jam the hammers
- Layout variants: QWERTZ (German, Y and Z switched), AZERTY (French), French Canadian
- Dvorak and Colemak are alternative layouts optimized for typing speed
- Modifier keys (Shift, Ctrl, Alt, Cmd) change what other keys do
- The Shift key is called that because on typewriters it physically shifted the mechanism to type capitals
- Shortcuts like Ctrl+C, Ctrl+V, Ctrl+Z build muscle memory and save time

## Week 5 - CLI (Command Line Interfaces)
- Before CLI there was batch mode: programs were prepared on punch cards, an operator ran them, results came back as paper printouts
- Early terminals like the DECwriter (1974) printed output on paper
- CLI = Command Line Interface, we type commands instead of clicking
- `pwd` shows the current folder, `ls` lists files, `cd` changes folder
- SSH is the (almost) universal remote control - we used it in the Bandit lab
